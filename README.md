# РОБКОН — сайт проекта

Статический одностраничный сайт для публикации на GitHub Pages.

## Состав
- `index.html` — страница, стили и JavaScript.
- `assets/robocon-hero.svg` — текущий концептуальный визуал продукта.
- `assets/fasie.svg` — логотип Фонда содействия инновациям.
- `.nojekyll` — отключение Jekyll на GitHub Pages.

## Обязательный грантовый блок
На первом экране размещены:
- логотип Фонда содействия инновациям;
- логотип Платформы университетского технологического предпринимательства (подключен с официального сайта Платформы по URL);
- обязательная формулировка о поддержке проекта.

## Важно
Цена на сайте намеренно не указана: в проектных материалах встречаются разные значения, поэтому до фиксации актуальной коммерческой цены её лучше не публиковать.

## Фотографии продукта
На странице предусмотрен раздел «Примеры продукта» с тремя плейсхолдерами.
Когда будут готовы фотографии, их можно сохранить, например, как:
- `assets/product-01.jpg`
- `assets/product-02.jpg`
- `assets/product-03.jpg`

После этого плейсхолдеры в `index.html` заменяются обычными тегами `<img>` с этими путями. Подписи под фотографиями можно менять отдельно.
